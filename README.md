# Handwritten Digit Recognition using CNN

This project implements a Convolutional Neural Network (CNN) to recognize handwritten digits using the MNIST dataset. A Streamlit web application is developed to provide an interactive interface where users can upload handwritten digit images and receive real-time predictions.

## Features

- CNN model built using TensorFlow and Keras
- Trained on the MNIST handwritten digit dataset
- Image preprocessing and normalization
- Real-time digit prediction
- Interactive Streamlit web application
- Displays prediction confidence
- Simple and user-friendly interface

## Dataset

- MNIST Handwritten Digits Dataset
- 60,000 Training Images
- 10,000 Testing Images
- Image Size: 28 × 28 pixels
- Classes: Digits (0–9)

## Technologies Used

- Python
- TensorFlow
- Keras
- NumPy
- Pillow (PIL)
- Streamlit
- Matplotlib
